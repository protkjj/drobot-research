## 1. 배경 및 문제 제기

선행 실험에서 A\* 와 RRT\* 를 비교하는 과정 중, **최적해가 모드 전환(비행)을
단 한 번도 선택하지 않는 현상**이 관측됨. 대상 5개 맵 전체에서 동일하게 나타남.

하이브리드 경로계획을 검증하는 실험에서 비행이 선택되지 않을 경우,
실질적으로 2D 지상 경로계획 문제를 푸는 것과 동일하므로 실험의 타당성이 성립하지 않음.

원인 규명을 위해 다음을 순차적으로 시도하였음.

| 시도 | 조치 | 결과 |
|---|---|---|
| 1 | 맵 재설계 (장애물을 좁고 길게) | 비행 미선택 |
| 2 | 우회거리를 손익분기(7.3~10.3m) 이상으로 확대 | 비행 미선택 |
| 3 | takeoff 에너지 파라미터 sweep (0.1~5.0 Wh) | 부분적 개선에 그침 |
| 4 | **비용함수 표현 형태 변경** | **비행 선택됨** |

본 문서는 4번 조치의 근거와 효과를 정리한 것임.

---

## 2. 비용함수 형태

### 2.1 변경 전 — 가중합 형태

```
C = α·E_motion + β·E_switch + γ·T
α = 1.0,  β = 1.0,  γ = 0.5
```

에너지(Wh)와 시간(s)을 직접 합산하는 구조이므로 단위가 혼재함.
가중치가 물리량 간 단위 변환 계수를 겸하게 되어, 각 항의 실제 기여도를
계수만으로 판단할 수 없음.

### 2.2 변경 후 — 정규화 형태

```
C = wE·(E_motion / E_ref) + wS·(E_switch / E_switch_ref) + wT·(T / T_ref)
wE = 0.5,  wS = 0.2,  wT = 0.3     (합 = 1.0)
```

각 항을 참조값으로 나누어 무차원화함. 가중치의 합을 1로 두어 비중을 직접 해석 가능.

참조값은 상수로 고정하지 않고 모델 파라미터에서 유도함.

```
E_ref        = ground_mode.energy_per_meter        (평지 1 m 주행 에너지)
E_switch_ref = takeoff_energy + landing_energy     (모드 전환 1회 에너지)
T_ref        = 1 / ground_mode.speed               (평지 1 m 주행 소요시간)
```

### 2.3 두 형태의 동등성

두 형태는 다음 관계로 정확히 동등함.

```
α = wE / E_ref
β = wS / E_switch_ref
γ = wT / T_ref
```

따라서 본 변경은 **동일한 비용함수의 표현 방식을 바꾼 것**이며,
최적화 대상 자체를 변경한 것이 아님.

---

## 3. 변경 전 설정의 문제

변경 전 계수(α=1.0, β=1.0, γ=0.5)를 정규화 형태로 환산한 결과는 다음과 같음.

| 항목 | 환산 가중치 | 비중 |
|---|---|---|
| 에너지 (wE) | 0.500 | 4.9% |
| 모드 전환 (wS) | 8.000 | **78.7%** |
| 시간 (wT) | 1.667 | 16.4% |

**모드 전환 페널티가 전체 비용의 78.7%를 차지하고 있었음.**
에너지 항의 비중은 4.9%에 불과하여, 에너지 인식 경로계획이라는 설계 목적과
실제 최적화 대상이 불일치하는 상태였음.

이는 최적해가 비행을 선택하지 않은 직접적 원인으로 판단됨.
단위가 혼재된 표현에서는 이러한 불균형이 계수만으로 드러나지 않음.

## 4. 실험 방법

- 대상 맵: `easy_open`, `easy_corridor`, `medium_open`, `medium_corridor`, `hard_open`
- 격자 해상도: 0.1 m
- 시간 제약: 2.0 초 (`hybrid_astar_params.yaml`의 timeout)
- RRT\* 시드: 20개 (평균 및 표준편차 산출)
- 스무딩: 양 플래너에 동일 적용
- **에너지 파라미터는 두 조건에서 동일하게 유지하고, 가중치 표현만 변경함**

재현 스크립트: `benchmark/exp_costfn_ablation.py`

## 6. 고찰

### 6.1 하이브리드 동작의 회복

변경 전에는 전 맵에서 비행이 선택되지 않았으나, 변경 후 `medium_open` 및
`hard_open`에서 각 2회(이륙 1 + 착륙 1)의 모드 전환이 발생함.
해당 맵은 3D 상태공간에서 통과 불가능한 높이(0.95 m 초과) 장애물을 포함하도록
설계된 맵이며, 설계 의도대로 비행이 선택된 것으로 확인됨.

### 6.2 알고리즘 비교 결론에 미친 영향

A\* 는 두 조건 모두에서 5/5 우위를 유지하였으므로, **알고리즘 선택 결론은 불변임.**

다만 평균 마진이 +3.09%에서 +2.08%로 감소함. 비행이 선택되면서 탐색 문제의
난이도가 상승하였고, 이에 따라 A\* 의 격자 이산화 페널티가 상대적으로
드러난 것으로 해석됨. 즉 변경 전 조건에서 관측된 큰 마진에는
**문제 난이도가 낮았던 요인이 일부 포함되어 있었음.**

이 결과는 선행 문서의 판단, 즉 A\* 채택의 실질적 근거가 해 품질이 아니라
최적성 보장·결정론적 재현성·시간 여유에 있다는 결론을 보강함.

### 6.3 가중치 해석 가능성

정규화 형태에서는 가중치 합이 1이므로 임무 목적을 직접 표현할 수 있음.

```
에너지 우선   wE = 0.7,  wS = 0.2,  wT = 0.1
균형형        wE = 0.5,  wS = 0.2,  wT = 0.3   (현재 설정)
시간 우선     wE = 0.3,  wS = 0.1,  wT = 0.6
```

### 6.4 실측 파라미터 변경에 대한 안정성

참조값을 파라미터에서 유도하는 구조이므로, Phase 2 실측을 통해
에너지 파라미터를 교체하더라도 가중치의 의미가 보존됨.
`wE = 0.5`는 파라미터 변경 후에도 "평지 1 m 주행 대비 기준"을 유지함.

## 7. 한계

### 7.1 비용 절대값 비교 불가

변경 전 44.506 과 변경 후 16.289 는 스케일이 상이하므로 직접 비교할 수 없음.
비교 가능한 지표는 동일 조건 내의 상대값(A\* 우위 %)과 경로 특성(모드 전환 횟수)에 한정됨.

### 7.2 가중치 선정의 근거 부족

현재 가중치(0.5 / 0.2 / 0.3)는 균형형이라는 명목으로 설정한 값이며,
실측 또는 최적화를 통해 도출한 값이 아님.

향후 JMP 를 이용하여 `wE, wS, wT` 를 sweep 하고
total_energy / total_time / switch_count 를 desirability 로 평가하면
임무별 적정 가중치를 근거 있게 결정할 수 있을 것으로 판단됨.

### 7.3 에너지 파라미터 미실측

`takeoff_energy = 5.0 Wh` 는 동일 config 의 `hover_power = 50 W`,
`takeoff_time = 5 s` 로부터 산출한 값(50 W × 5 s = 0.069 Wh)의 약 72배에 해당함.

비용함수의 표현 형태를 개선하더라도 파라미터 자체가 부정확할 경우
결론의 타당성이 확보되지 않음. **Phase 2 실측의 최우선 대상임.**

---

## 8. 결론

1. 비용함수를 정규화 형태로 변경한 결과, 기존 설정이 모드 전환에
   전체 비용의 78.7%를 배분하고 있었음이 확인됨. 이는 최적해가 비행을
   선택하지 않은 원인으로 판단됨.

2. 가중치를 0.5 / 0.2 / 0.3 으로 재설정한 후 모드 전환이 정상적으로
   선택되었으며, 하이브리드 경로계획 실험의 타당성이 확보됨.

3. A\* 채택 결론은 두 조건에서 모두 유지됨. 다만 평균 마진이
   +3.09%에서 +2.08%로 감소하였으며, 이는 A\* 채택 근거가 해 품질보다
   최적성 보장·재현성·시간 여유에 있다는 선행 판단을 뒷받침함.

4. 단위가 혼재된 비용함수는 가중치의 실제 기여도를 은폐함.
   본 사례에서 이상 결과의 원인 진단이 지연된 주된 요인이었음.
